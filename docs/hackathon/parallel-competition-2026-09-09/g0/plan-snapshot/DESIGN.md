## 产品意图

新增工作台优先复用成熟开源 UI/交互：**Ant Design 为新业务组件与主题规范；DSH 为唯一 Agent 执行与原生能力基座；StaffDeck 仅参考员工/任务/成果组织**。不引入第二运行时。旧 Vue 保留既有主题令牌，新 React 业务通过 ConfigProvider 和集中 token 映射统一；DSH 原生组件通过受控适配与同一品牌协调。组件库/技能能支持设计，不能代替真实视觉验收。

当前主路径是自由问数 → 可追溯诊断 → 认可后批量成板 → 拖拽/缩放与点选聊天编辑 → 召回候选 → 行动草稿。首屏突出提问和已有驾驶舱；老板能从证据决定试点方向。下文 Mission-first 组件仅描述旧 Vue Mission，不将审批作为新分析/候选预览的前置条件。

## 设计令牌

现有 Vue 页面设计令牌的单一事实来源是 `frontend-vue3/src/theme.ts`。该文件同时导出 CSS Variables 和 Naive UI theme overrides；当前增长董事会、登录页与全局头部不得直接写品牌色、玻璃透明度或发光阴影字面量。

尺寸也由 `shineMageTheme.dimension` 统一导出为 `--sm-dimension-*`，覆盖这三个界面及五个业务模块的字号、间距、宽高、位移、字距和视口尺寸。百分比、网格比例和无单位值保留为相对布局表达式。CSS 自定义属性不能用于媒体查询条件，因此断点由 `shineMageTheme.breakpoint` 登记，契约测试核验各组件的媒体查询常量与其一致。不要为修改单个页面尺寸重新引入局部字面量。

| 角色 | 值 | 用法 |
|---|---|---|
| Deep Plum | `#09050D` | 沉浸式主背景 |
| Brand Purple | `#805D9D` | 品牌主色、状态线、次级动作 |
| Soft Lilac | `#D3C3E8` | 文字层级、玻璃边界 |
| Signal Lime | `#F2FFDC` | 确认状态、决策信号、关键数字 |
| Ink White | `#FEFCFF` | 标题与主数字 |
| Danger | `#FF7D91` | 错误与风险 |

玻璃层采用 `rgba(255,255,255,0.03)` 叠加深紫黑页面背景，使用细描边、背景模糊和顶部高光。预估毛利主数字使用浅紫白渐变与浅紫微光；荧光浅绿用于确认信号，不作为大面积卡片背景；审批主操作使用帝王紫渐变。对应材质、渐变和阴影均在主题中定义，不能退回较不透明的深紫卡片。

## 字体

- 中文：`Alibaba PuHuiTi 3.0` → `PingFang SC` → `Microsoft YaHei`
- 英文与数字：`Outfit` → `SF Pro Display` → 系统无衬线
- 代码与数据版本：`SFMono-Regular` → `Menlo` → 等宽字体

Outfit 使用仓库内固定修订的可变字体，通过 `styles/fonts.css` 同源加载，不依赖外部 CDN；资产来源、校验值与许可见 `frontend-vue3/src/assets/fonts/README.md`。中英混合标题的 display 栈通过 `var(--sm-font-body)` 复用中文回退。普惠体 3.0 当前未捆绑，不能把字体栈声明视为加载成功；本机实测中文回退为 PingFang SC。

Figma 中文已获准映射 Noto Sans SC，英文/指标使用 Outfit；这不改变 Web 字体回退栈。可编辑稿、变量镜像和代码对应关系见 `docs/hackathon/FIGMA-SYNC.md`；不宣称两种渲染引擎像素级一致。

## 布局原则

自由问数框仅在聚焦期间运行克制的呼吸光效，周期与两端阴影都来自主题令牌；系统开启“减少动态效果”时禁用呼吸动画，保留静态焦点光圈。

1. 桌面首屏按“命题与收益 → 渠道资产与问数 → 审批执行”由上到下阅读。
2. 规模、质量、执行抓手必须并排呈现，避免把最大流量误当最佳客户资产。
3. 自由问数必须展示受控语义层和局限，不能伪装成任意 SQL。
4. 新主线允许获授权用户预览召回候选与行动草稿；导出和真实发送各自执行权限/审批。旧 Mission 的 `DRAFT_EXPORT` 审批状态机仍保留，不自动触达真实用户。
5. 移动端转为单列，但审批与 synthetic data 边界不能隐藏。

## 组件边界

- `NavBar` + `BrandMark`（对应设计需求的 `Header`）：魔术帽、标准字、副标题、主导航与登录申请。
- `MissionHero` + `ImpactForecast`（对应 `HeroMetric`）：今日经营命题、规模/质量冲突、AI 建议、收益假设与 90/10 实验规模。
- `ChannelPortfolio`（对应 `ChannelTable`）：首付费渠道、二单率、跨渠道率与净价值。
- `BusinessQuery`（对应 `QuerySection`）：受控自由问数与可追溯回答。
- `MissionActionRail`（对应 `ApprovalWorkflow`）：状态机、审批、草稿导出与演示重置。

旧 BI / Mission 属于 Vue 3，继续使用 `.vue`；拟接入的 DSH 业务插件遵循上游 React/TypeScript 组件与插槽，不把两种组件源码互相复制。旧 Vue theme.ts 不直接作为 React 组件源码依赖；新 React 业务建立集中 Ant Design tokens，沿用本文件品牌和字体资产。优先官方主题/插槽，缺口集中在有版本和回归矩阵的前端适配层，禁止散布全局选择器或改固定上游源码。技术设置保留可访问入口；所需第三方版权在许可文件/关于页保留。具体承载验证见 DSH 交互设计。

## 禁止项

- 不使用蓝青色“科技大屏”模板语法。
- 不使用紫色渐变标题、无意义发光、气泡式卡片堆叠。
- 不用模拟数据冒充真实经营结论。
- 不在 UI 绕过审批、幂等键、版本控制或实验对照组。
