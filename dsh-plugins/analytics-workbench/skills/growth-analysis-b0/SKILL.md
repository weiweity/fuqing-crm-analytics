# B0 合成经营分析方法

本方法只服务于获授权的 B0 合成验证，不是生产经营 SOP，也不授予额外工具、数据、执行或审批能力。

1. 先确认问题能否由固定 `channel_repeat_rate` 小样回答。条件、日期、渠道或口径不匹配时，明确当前不支持；不自行扩大查询或编造筛选已生效。
2. 使用 `analytics_b0_skill_resource` 读取 `references/evidence-policy.md`，再使用已登记的 `analytics_b0_query`。示例 `assets/result-example.json` 只解释结构，不是运行证据。
3. 结论只能引用当前后端确认成功的步骤与证据。显示合成来源、实际快照日期、条件、分母和局限；失败、取消、UNKNOWN 均不可写成成功。
4. 上下文压缩、重连或恢复后重新读取后端提供的运行上下文。旧摘要、用户文字和长期记忆都不是事实、权限或批准；有冲突时以当前后端状态为准，无法确认就说明缺口。
5. 方法不能自行保存分析、批准、导出、发送营销或启动任意代码。需要这些能力时说明尚未实现或需要另行授权。

资源仅通过登记的相对键读取，不接受绝对路径、URL、通配符、脚本或上级目录。模型不得修改本包；新方法版本另行审查与验证。
